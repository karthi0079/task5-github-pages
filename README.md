# Task 5: Host a Static Website with GitHub Pages

## Objective
Deploy a static website using GitHub Pages and make it accessible online for free.

## Technologies Used
- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

## Project Description
Created a responsive developer portfolio website using HTML and CSS. The website includes an introduction, technical skills, projects, and contact information. GitHub Pages is used to host the website publicly without requiring paid hosting services.

## Project Structure
```text
task6-github-pages/
├── index.html
├── style.css
├── README.md
└── assets/
```

## Implementation Steps
1. Created the `index.html` file to structure the website.
2. Created the `style.css` file to style the website.
3. Initialized a Git repository locally.
4. Created a new public GitHub repository.
5. Added and committed the project files using Git.
6. Pushed the code to the `main` branch.
7. Enabled GitHub Pages through repository Settings.
8. Selected the `main` branch and root folder (`/`) as the publishing source.
9. Verified that the website was successfully deployed and accessible online.
